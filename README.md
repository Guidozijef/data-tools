# DataClean Studio (数据清洗与数据库导入转换工具)

> 纯前端、零后端依赖的旧数据清洗、字段智能关联映射、数据库导入与 Excel 导出平台。
> 基于 **Vue 3 + Vite + SheetJS (XLSX)** 开发，所有数据均在浏览器本地内存中处理，确保数据绝对隐私安全。

---

## 🌟 核心特性与解决的痛点

在企业系统重构、老系统向新系统数据迁移时，往往面临如下痛点：
1. **旧数据分散在 Excel / CSV 中**：字段命名随意、含空格、格式杂乱。
2. **字段无法直接对应数据库**：老系统使用“客户编号”、“联系电话”，现有数据库需要 `user_code`、`mobile`。
3. **脏数据严重**：
   - 手机号带有 `+86`、空格、破折号；
   - 金额带有货币符号 `¥`、`$`、千分位逗号 `,`、文字 `元`；
   - 性别、状态等为汉字“男/女/启用”，数据库需要存储为枚举整数 `1/2/0`；
   - 日期时间格式混乱（如 `2021/4/15`、`2021.06.22`、`2022年08月18日`、Excel时间戳数字），需统一规整为 `YYYY-MM-DD HH:mm:ss`；
   - 存在重复记录、全空行、必填字段缺失。
4. **导入数据库繁琐**：通常需要写 Python 脚本或手动编写 SQL。

**DataClean Studio** 提供开箱即用的一站式纯前端解决方案！

## 🚀 五步向导式工作流程

### 步骤 1: 数据源上传与多 Sheet 页签解析 (`StepUpload.vue`)
- **拖拽与选择上传**：支持 `.xlsx`、`.xls`、`.csv`。
- **多工作表 (Tab 页签) 显式选择**：当上传的 Excel 包含多个 Sheet 时，系统自动罗列所有工作表卡片，支持**点击自由选择导入具体哪一个 Tab 页签**，且支持随时无缝切换预览。
- **表头定位**：支持自定义表头位于第几行（应对首行为统计说明的特殊表格）。
- **内置演示数据**：提供“老系统客户信息与多层JSON扩展”丰富演示数据，一键载入体验完整流程。

### 步骤 2: 目标数据库结构配置 (`StepTargetSchema.vue`)
- **SQL 建表 DDL 一键解析**：直接粘贴 `CREATE TABLE ...` 语句，自动提取表名、字段名、类型、精度、注释、主键及 NOT NULL 约束。
- **Excel 列名一键克隆**：快速将 Excel 的所有列一键映射为目标表字段。
- **可视化字段编辑器**：支持自由添加、删除、编辑字段类型（`varchar`、`int`、`decimal`、`datetime`、`date`、`boolean`、`json` 等）。

### 步骤 3: 字段关联映射、多层 JSON 提取与自定义 JS 清洗 (`StepMapping.vue`)
- **智能一键匹配 (Smart Auto Match)**：基于中英文词义、同义词库、拼音及下划线忽略算法，自动将 `联系电话` 匹配给 `mobile`，`客户姓名` 匹配给 `username`。
- **多样化来源支持**：
  - **单字段映射**：普通文本/数值列。
  - **📦 多层嵌套 JSON 字段提取 (`json_path`)**：
    - **自动探测所有 JSON 节点路径**：系统自动读取样本行，以可视化卡片展示所有深层节点（如 `source.channel`、`profile.address.city`），展示真实样本值，**点击节点即可一键绑定**！
    - **支持单属性提取**：如 `profile.address.city`。
    - **支持多深层属性拼接**：如将 `profile.address.province` + `profile.address.city` + `profile.address.street` 以空格或破折号拼接为完整收件地址！
    - **提取后可无缝级联标准清洗规则**（如去除空格、字典转换、格式化等）。
  - **⚡ 自定义 JavaScript 复杂清洗引擎 (`custom_js`)**：
    - 面对无法用简单拼接完成的极端复杂业务规则，提供**内置 JS 代码编辑器**！
    - 形参直接提供：
      - `val`：当前单元格原始值
      - `row`：包含整行 Excel 列的对象（如 `row['数量']`、`row['单价']`）
      - `json`：**若源列是 JSON，系统已预先反序列化为原生 JS 对象**，可直接通过 `json?.metrics?.score` 访问！
      - `index`：行序号
    - **内置常用代码片段**：三元判断、JSON条件评级、多列数学运算、多分支 if-else 函数等。
    - **实时沙箱测试 (Live Sandbox)**：边写代码，下方即时展示在真实前 3 行数据上的运行结果与报错预警。
  - **🔗 多列文本合并 (`combine`)**：如多列直接拼接。
  - **固定常量 (`constant`)**：如固定写死导入批次号或租户 ID。
  - **忽略字段**：使用数据库默认值或 NULL。
- **丰富的字段清洗转换规则**：
  - **文本清洗**：去除前后空格 (Trim)、连续空格规整、全空格去除、大写转换、小写转换。
  - **手机号格式化**：自动剥离 `+86`、括号、破折号，规整为标准11位。
  - **金额/数值提取**：剥离货币符号 `¥`、`$`、文字“元”、千分位逗号，自定义保留小数位精度。
  - **日期时间规整**：自动识别点号、斜杠、中文年月日及 Excel 日期序列数，统一输出为 `YYYY-MM-DD HH:mm:ss`、`YYYY-MM-DD` 或时间戳。
  - **枚举与字典映射 (Dict Mapping)**：提供可视化键值映射编辑器（如 `男 -> 1, 女 -> 2, 未知 -> 0`），支持未匹配值回退。
  - **敏感信息脱敏**：手机号打码 `138****1234`、身份证号打码。
- **全局行级规则**：
  - 基于指定主键字段自动去重 (Keep First / Keep Last)。
  - 自动过滤清洗后全空数据行。

### 步骤 4: 实时清洗预览与行内纠错 (`StepPreview.vue`)
- **数据健康度仪表盘**：实时展示清洗有效行数、校验通过率、异常/警告行数、去重丢弃行数。
- **实时校验高亮**：对缺失必填项 (NOT NULL)、类型不匹配 (如数值列填入字符串)、日期无效等给出红色高亮与提示气泡。
- **表格行内直接编辑 (Inline Edit)**：双击或直接点击任意单元格即可原地修改，修改后实时重新触发校验！
- **源数据 vs 清洗后数据 对比视图**：随时查看某行原始数据与清洗后结果的对照。
- **多维度筛选**：支持“仅看异常数据”快速排查，支持全局关键词搜索。

### 步骤 5: 导出与数据库导入 (`StepExport.vue`)
- **直接生成数据库 SQL 脚本**：
  - 支持 **MySQL**、**PostgreSQL**、**SQLite**、**Oracle** 方言。
  - 支持 `INSERT INTO`、`INSERT IGNORE`、`REPLACE INTO`、`ON DUPLICATE KEY UPDATE`。
  - 支持分批插入（如每 200 行一个批量 SQL）。
  - 支持一键复制或下载为 `.sql` 文件，直接导入 Navicat / DBeaver / 生产数据库。
- **导出清洗后的 Excel (.xlsx)**：自定义文件名、工作表名称、表头中英文字段选择。
- **导出 CSV**：内置 **UTF-8 with BOM** 编码，Windows Excel 直接双击打开永不乱码。
- **导出 JSON**：结构化数据文件。

### 方案模板管理 (`TemplateManagerModal.vue`)
- 支持将当前配置（目标表结构 + 映射关系 + 清洗规则）保存为方案模板（保存在浏览器 LocalStorage）。
- 支持导出为 `.json` 模板文件，或导入已有模板文件，实现多批次导入一键复用。

## 🛠️ 本地运行与构建

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 生产环境打包
npm run build
```

## 🔒 隐私与安全性
本项目为 **100% 纯前端静态应用**，所有 Excel 解析、清洗算法、数据校验、SQL 生成均在用户的浏览器端完成，没有任何数据会发送至第三方服务器，完全安全合规。
